# Kishu Inu Creative Archive

This repository preserves recovered and community-collected visual/media assets related to Kishu Inu, its historical ecosystem projects, and Tenshi.

It is a creative/media archive, not a contract repo, frontend repo, token migration repo, or proof of current project control.

## Current Layout

### `00 - Raw Archive  - 2021-04 to 2026-05`

Raw recovered material and older folder structures.

Use this as the historical source bucket. Files in this folder may be duplicated, unsorted, obsolete, low-quality, or tied to old claims. Do not treat a file being here as proof that a campaign, product, partnership, or project is currently active.

### `01 - Kishu Inu Core`

General Kishu Inu token/community creative material.

Current subfolders include:

- `Logo` - Kishu logo files and logo variants.
- `Mascot` - Kishu mascot art and character files.
- `Profile Picture` - profile/avatar images.
- `Banners` - general banners and header-style graphics.
- `Community Images` - general holder/community-use images that do not fit a more specific campaign folder.
- `Countries` - country/community flag or localized graphics.
- `Charity Work` - charity-related campaign images and videos.
- `Global Events` - location/event marketing graphics and videos.
- `Partnerships` - partner announcement or partner-related graphics.
- `Memes` - meme-style images.
- `Videos` - general Kishu videos.

### `02 - Kishu Community Projects`

Visual material for Kishu-branded ecosystem/project claims, products, or recovered project areas.

Current project folders include:

- `00 - Kishu Swap`
- `01 - Kishu Paw Print`
- `02 - Kishu Swag`
- `03 - Kishu Crate`
- `04 - Kishuverse`
- `05 - Kishu Kingdom`

Use these folders for project-specific logos, screenshots, NFT/media references, promo graphics, teaser images, and recovered visual assets. Project code, contract source, and technical breakdowns should stay in their own repos.

### `03 - Tenshi`

Tenshi-specific creative material.

Tenshi was a separate token/project area, so its assets should stay separated from Kishu Inu core assets unless a file clearly contains both projects.

## Sorting Rules

- Keep the raw archive intact when possible. Move or copy curated material into the organized folders, but avoid deleting old source material unless it is an obvious duplicate or junk file.
- Put general Kishu token/community images under `01 - Kishu Inu Core`.
- Put Kishu Crate, Kishuverse, Kishu Kingdom, Kishu Swap, Kishu Paw Print, and Kishu Swag visuals under `02 - Kishu Community Projects`.
- Put Tenshi-only assets under `03 - Tenshi`.
- Use `Community Images` only for broad community-use graphics. If a file fits `Charity Work`, `Global Events`, `Countries`, `Partnerships`, `Banners`, `Memes`, or a specific project folder, use the more specific folder.
- Keep generated modern social-media post graphics in the separate `social-media-posts` repo unless they are reusable creative assets.
- Keep contract/source-code documentation in `Kishu-Inu-Contracts` or the matching recovered project repo, not here.

## What This Repo Is Not

This repository does not prove current control of the KISHU token contract, former team wallets, NFT collection owner wallets, websites, or social accounts.

This repository does not announce a migration, refund, recovery claim, wallet verification flow, or airdrop.

Historical graphics can contain old claims, outdated domains, old links, or promotional language from the original project era. Treat those as historical artifacts unless current public documentation verifies them.
